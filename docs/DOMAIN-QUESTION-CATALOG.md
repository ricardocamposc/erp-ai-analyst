# ERP AI Analyst — catálogo de preguntas

Este catálogo define preguntas de aceptación para el asistente. Cada área tiene
50 preguntas: 20 operativas (O), 20 de gestión (G) y 10 estratégicas (E).
Las preguntas que requieren datos deben resolverse con tools determinísticas;
las preguntas conceptuales deben responderse con conocimiento ERP explícito y
sin inventar datos de la empresa.
