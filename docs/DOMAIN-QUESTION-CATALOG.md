# ERP AI Analyst — question catalog

This catalog defines acceptance questions for the assistant. Each area has 50
questions: 20 operational (O), 20 management (G), and 10 strategic (E).
Questions requiring data must be resolved with deterministic tools; conceptual
questions must be answered with explicit ERP knowledge without inventing
company data.
