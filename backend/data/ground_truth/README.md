# Slice 1 ground truth

These files are human-reviewable expectations for the deterministic synthetic ERP.
They are maintained separately from the future analytical services and are not
generated by domain-service code.

The dataset uses USD, calendar-month periods, ISO dates, `unit` quantities and
the fixed generator seed `20250824`. March 2025 is the deliberately explainable
sales-decline target period; February 2025 is its comparison period.
